# RealtimeVAD reference

RealtimeVAD/ is the retained original source reference. The existing .venv and
VAD dependency lists are preserved. Install RealtimeVAD as a package for runtime use.

The active app uses LatentSync-trial/vad.py for custom pause policy and
LatentSync-trial/vad_timestamps.py for its worker interface.

Historical app experiments and results were moved to archive/vad-experiments/.
Background separation lives separately in ../background-audio/.
